# VareiShopBot 🤖

Bot do Telegram para publicar ofertas de afiliados automaticamente.

## 📋 Sobre o Projeto

O **VareiShopBot** é um bot do Telegram que permite publicar ofertas de forma rápida e automática em grupos/canais. Basta enviar um link de afiliado e o bot cria uma mensagem personalizada e publica instantaneamente.

## 🚀 Funcionalidades

- ✅ Recebe links de afiliado (Shopee, Mercado Livre, etc.)
- ✅ Cria mensagens personalizadas automaticamente
- ✅ Publica no grupo/canal do Telegram
- ✅ Interface simples e intuitiva
- ✅ Resposta instantânea
